# OctoAcme Project Management Docs

This README provides a short summary of OctoAcme's project management processes and direct links to the full process documents stored in the docs/ folder.

## Quick summary of OctoAcme project management processes

OctoAcme runs iterative, customer-focused projects with clear ownership and measurable outcomes. Key practices include:
- Small, testable increments and iterative delivery
- A clear lifecycle: Initiation → Planning → Execution → Release → Retrospective
- Regular communication cadence: daily standups, weekly delivery syncs, and demos/reviews
- Defined artifacts: project one-pager, backlog, acceptance criteria, risk register, release notes
- Explicit escalation paths for blockers and incidents
- Emphasis on data-informed decisions and continuous improvement
